How it works

Three steps instead of manual dimensioning

Every size is measured from the layer itself, so there is nothing to type in.

Install

Run the installer and restart Photoshop. The panel appears under Window → Extensions → Размеры фото.

Open your template

Background layer at the bottom, photo layers of any size on top. Move and duplicate them as usual.

Press the blue button

The height and width of every photo get labelled in millimetres. It is a single history step, so Ctrl+Z undoes it.

Features

Built for working with photo sheets

No hand-drawn lines, no calculator, no clutter of settings.

Any size

3×4, 35×45, 10×15 or custom: the size is taken from the layer bounds.

Height and width on every photo

Height on the side, width below: arrows, extension lines and digits like on a drawing.

Part of the raster

Labels live in a layer group called «Размеры». They stay on the picture when you save JPG or PNG.

Adjustable

Digit height, distance to the photo, line thickness, side of the label. Values are remembered.

Smart layer selection

Skips the background, full-sheet layers, text and adjustment layers. Name a layer starting with “_” to exclude it.

No cloud, no account

Works offline and needs neither Adobe Creative Cloud nor a sign-in.

FAQ

Frequently asked questions

The panel is not in the Extensions menu. What now?

Close Photoshop completely (check Task Manager) and start it again. The panel is under Window → Extensions → Размеры фото.

Some portable or modified Photoshop builds have panel support removed. In that case use the script: it does the same thing and runs from File → Scripts.

Which Photoshop versions are supported?

The panel is built for Photoshop CC 2015 and newer. The script works wherever the File → Scripts menu exists.

Windows shows a warning when I run the installer

The file has no paid digital signature, so SmartScreen may say “Windows protected your PC”. Click “More info”, then “Run anyway”. The installer works only inside your user account, changes nothing system-wide and needs no administrator rights.

Which layers get labelled?

All visible layers above the bottom (background) layer. Skipped: full-sheet layers, text and adjustment layers, layers smaller than 5 mm and layers whose name starts with “_”. Sizes come from the document resolution, so your template needs the correct one, for example 300 ppi.

How do I uninstall?

Run the installer again and choose “Uninstall”, or open Settings → Apps. If you installed manually, delete the PhotoSizeLabels folder from the extensions folder.

Is the interface in English?

The installer is bilingual. The panel buttons and the unit on the labels (“мм”) are in Russian for now. You can replace the unit with your own in the script settings, parameter unitText.

Is it free? May I share it?

It is free to use, including commercial work. Redistribution is not allowed: no re-uploading, repackaging or reselling. Please share a link to this page instead. The terms are in the LICENSE file in the repository.
